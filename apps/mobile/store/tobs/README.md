# Tobs / 托布 — iOS promotional artwork

Twelve branded variants of the existing iOS campaign: seven English compositions (three dark), five Simplified Chinese compositions. Each PNG is 1320 × 2868, with the complete phone frame and an exterior Tobs/托布 wordmark plus `tobs.app`. The originals and native captures remain unchanged in their task evidence batches. `manifest.json` records the original poster, capture source and output hashes.

These are **generated marketing compositions**, not native screenshots or proof of the renamed app binary. Codex built-in imagegen edited the existing posters, and SIPS converted dimensions. No new app controls or product features were requested. Compare the phone content with the source captures during final editorial acceptance (#2736). Community README text and repository names can still contain historical DeepSeekBot; official DeepSeek model and DeepSeek Harness names remain accurate.

## Prompt direction

Edit only exterior branding of the existing composition. Add the verbatim wordmark `Tobs` (English) or `托布` (Chinese), with `tobs.app` below it, outside and below the complete phone. Keep the headline, UI text, avatars, controls and light/dark palette. Keep all phone edges and the home indicator visible; reduce the composition or extend the matching background if needed. Do not invent icons, controls, AI labels or a watermark. Two Chinese footer variants were corrected to remove invented logo artwork.

Uploading these candidates to the existing App Store Connect draft does not submit the app for App Review or publish a release. App Store Connect record, bundle IDs, EAS project, signing, App Groups, storage and deep-link schemes remain the existing identities. Native naming and upgrade verification are recorded separately on #2725.
