# 环境面板与双向 Host 连接

Human 在 2026-11-13 完成 Q1–Q28 并整体确认的目标设计，不代表已实现或已验收。它扩展 [#4069](https://github.com/BotHarness/DeepSeekBot/issues/4069)：原规格排除双向授权的边界仍是既有九个切片的历史范围。架构决定见 [ADR-0334](../adr/0334-host-relationships-authorize-independent-client-enrollment.md)。[English](environment-panel.md)。

## 面板与环境筛选

Environment 是 Control Rail 正式面板。Simple 模式替换当前面板，Advanced 模式新增独立列；布局保存在当前 Client。面板包含 All、本机与远程 Host，展示名称、图标、连接状态和未读数，提供每台 Host 的管理入口及常驻添加入口。首版不含 Cloud 工作区。邀请、配对与线路配置继续使用共享 Connections Modal，保留手机安装引导。

Channels 顶部筛选器与环境面板操作同一份 Client 本地持久化 Environment Scope，Chats 与 Activity 共用。首次默认 All，之后恢复上次选择；选中环境被移除时回到 All。筛选保留当前聊天，不改变已读状态或通知偏好；可见计数跟随筛选，面板每行保留对应 Host 的未读数。

All 按最近消息混合排列；多个环境存在时，头像右下角显示环境图标，重名条目补充环境信息。单 Host 视图展示并管理其 Channel Sections。别名和图标属于 Client 本地偏好，在各入口一致，不改变真实 Host 身份。

创建操作始终明确目标。All 默认上次创建 Host；目标离线时保留显示，要求明确选择在线 Host，不自动改成本机。仅一个可用目标时可预选。单 Host 视图使用该 Host。

## 连接与管理

持久关系及每客户端凭据边界以 ADR-0334 为准。手动连接由 A1 发起，A2 明确批准一次双向关系，保留适用的身份核对；同账号通过可信账号路径自动授权、连接并读取 Channels，无额外连接按钮。手机逐台加入，不自动继承其他 Host；Bot 协作独立手动启用。多条线路不产生多个环境。

A1→A2、A2→A1 分别报告可达状态，并引导补齐缺失线路。已授权但只通一个方向不标为双向已连接。关闭 Connections Modal 不停止已准备好的线路；可复用已有线路，返回、换方式或添加线路不重复创建生命周期。

解除双向连接明确列出双方，撤销关系派生权限，保留独立手机授权，并阻止同账号立即自动加回，直到主动重连。对方离线时保留待同步撤销，收到确认才标记完成。退出账号停止账号发现、新自动授权及官方服务，不自动撤销已有设备凭据或独立可用线路。移除选中环境后回到 All 并关闭其聊天、管理视图，不删除远端 Bots、Channels 或消息。

## 设置目标与离线行为

区分此应用偏好与环境设置。环境设置顶部常驻目标名称、图标及选择器，Settings Target 独立于聊天 Environment Scope；环境管理入口直接定位精确 Host，Bot 设置定位所属 Host。首版一次编辑一台 Host，不提供 All 批量写入。

远程 Bot 管理覆盖支持的名称、模型/预设、Workspace 和审批设置；Host 管理覆盖模型、用量、存储及连接。外观与通知偏好仍属当前 Client。各功能原有权限检查和确认不变；不支持远程处理的本地交互项目说明原因与操作指引。

有未保存内容时切换目标，提供保存并切换、放弃修改、取消。保存失败留在原目标；已发请求始终绑定原 Host，目标不可用时不退回本机。离线保留已加载列表与内容，发送、创建、远程写入需重连，不静默排队。

操作将关闭当前线路时，先验证并切换到可用替代线路；没有则明确确认断开，之后保留离线内容。连接丢失可能产生未知写入结果，重试前通过原 owner 回读，不能盲目重放。

远程连接设置复用所选 Host 的设备授权、单条私有路由与账号 owner。计划切换验证已有线路，明确保存本 Client 的手动偏好，等待实际连接切换并回读精确 Host 后才执行一次。私有路由停止须具名 `quick` 或 `custom`，保留其他线路。未知结果保护保存在已有 Client HostStorage 所有者下的独立执行键中，绑定 Host 公钥、设备、代次和操作/路由 ID，只描述执行状态，不成为 Host 配置权威，不会被 SavedHost 整体数组的旧写入擦除。共享 Web Lock 覆盖准备、保护持久化、一次写入和确认，回读在同一锁内重新读取并按代次清除；缺少 Web Locks 时拒绝写入。最多保留 32 条未解决事实，包括不转移或重试到新授权的旧设备事实。重载、迟到确认与原值未变均不触发重放。退出登录、关系断开和单设备撤销保持各自权威和效果。

## 所有权与交付状态

面板、筛选和设置目标属于应用定义的 Client 展示；布局不拥有 Host 关系或远程配置。Host Relationship 是 DSH Session 执行历史之外的应用持久数据，遵守 operational database 边界；秘密仍由现有凭据 owner 保护。Device Pairing 继续拥有设备授权；账号注册和 Bot 协作保持各自权威。API Gateway 仍是唯一 Host/Client API interceptor，UI 与 CLI 复用同一能力 owner；本文不规定新的具体远程 API。

当前 main 已有 Client 本地 RemoteHosts、Tab 选择与部分远程设置，但没有完整双向关系及此环境面板；移动端提供 Chats/Activity 共享筛选先例。这些不是目标功能已实现的证据。既有连接 stack 的本地 UI 修改与验收独立保留。

参考 T3 Code 官方源码 `2d8a843e6be9ca170f3bce98cc92ad76617b00c4` 的 SettingsScopeSentence、settings route、scopedSettings 和 useScopedSettings：借鉴明确设置范围、离线提示和目标绑定写入；所读导航层没有建立草稿保护保证，我们的保存/放弃/取消是独立确认需求。`reference/t3code` 是本地参考，不是产品依赖。

## 验收与性能

真实两 Host 验证手动双向 Channel 读写、其他桌面 Client 独立凭据复用、手机不继承、同账号自动连接、All/单 Host/角标/Sections/Activity/创建目标一致、远程写入目标准确、草稿与失败处理、离线撤销恢复确认且不自动加回，以及未知写入结果的回读与不重复执行。

复用现有能力、CLI 和测试，先交付可运行的双向连接纵向切片，再扩展设置及供应方式；分别记录 Web、安装版 Desktop 与移动端验收。实际旅程使用至少三组交错对照，报告中位数、范围和正确性，限制发现、探测、派生授权、待撤销记录及卸载后的活动。此文档变更无运行时影响，不声明产品提速或原生验收通过。
