# 任务看板

**任务看板** 是 **Channel sidebar** 里的只读进度面板。它只回答一个关于当前聊天的问题：这里的 Bot 正在做什么，做到哪一步了。

它不是任务管理器。你不能在面板里新建、修改、指派或关闭任何任务，面板自身也不存任务。

## 这个面板是什么，不是什么

- 它显示**当前聊天的 Assignment** —— 这个 Bot 私聊或这个群此前已经派出去的工作 —— 以及这些 Assignment 产生的执行步骤。
- 它显示的是**执行步骤**，也就是 Assignment 的每次工具调用。它**不显示** Assignment 内部的 `todo_write` 计划，也不替代[会话](/zh/docs/channel-sidebar/sessions)。
- 它**不是全局看板**。任务不会跟着你在聊天之间切换：每个聊天各有一套。让 Human 与 Bot 都能建卡、改状态、跨聊天持久的全局任务看板是另一项能力。

## 打开面板

- **宽窗口**：点击聊天头部齿轮旁的任务看板图标。悬停提示会写明动作 —— **打开任务看板**，打开后变为 **收起任务看板**。
- **窄窗口**：在侧栏覆盖面板中展开 **任务看板** 项目。
- 面板**默认关闭**，并且每个聊天各自记住开合状态。在一个聊天里打开它，不会让别的聊天也打开：切到你从没打开过的聊天，那里是关的；切回来，它仍然是开的。

## 面板里有什么

面板按 Bot 分组，每个 Assignment 一张卡片。

- 组与组之间按最近活动排序，组内卡片按最后更新时间排序。
- 群聊里每组**默认折叠**；折叠状态按 Bot 记住，后来加入的 Bot 同样默认折叠。
- 卡片显示 Assignment 标题、状态 chip（**进行中**、**待处理**、**空闲**、**已结束**）、`x/y 步`进度、当前正在跑的步骤，以及相对更新时间。
- 展开卡片可看步骤列表：完成的步骤保留勾选标记，进行中的高亮，失败的用错误色显示。
- 点击卡片打开执行过程弹窗，其中 **打开 Session** 会带你到 DSH 里对应的 Assignment。

进度统计的是面板已收到的步骤，因此写成 `12/15 步` 而不是百分比 —— 每个 Assignment 的步骤列表只保留最近 40 条，对一份被截断的列表算百分比会误导。

## 五种状态

| 状态       | 含义                                                                            |
| ---------- | ------------------------------------------------------------------------------- |
| 空         | 这个聊天还没有任何 Assignment。                                                 |
| 加载中     | 正在读取当前聊天的 Assignment。                                                 |
| 错误       | 读取失败，**重试**会再读一次。                                                  |
| 行级不可用 | 某个 Assignment 还在列表里，但它对应的 Session 已不可达；面板其余部分照常可用。 |
| 已截断     | 聊天里超过 200 个 Assignment，面板只显示最近 200 个并给出提示。                 |

如果刷新失败时面板上已有数据，它会保留这些数据并标记为**已过期**，而不是清空自己。

## 刷新与开销

- 面板打开时每 10 秒读一次当前聊天，且只在标签页可见时读。
- **关掉面板即卸载：零请求、零计时器。**
- 步骤是懒加载的：只对展开的分组、只对进行中或等待处理的 Assignment 读取，一次最多 4 个并发。折叠的分组和已结束的 Assignment 不会每轮重复读。
- 连续两次读取失败会停止自动刷新；用 **重试** 重新开始。

## 看板设置

面板右上角的齿轮打开三个只影响本面板的开关：

- **显示已完成步骤** —— 展开的卡片里隐藏已完成步骤，失败仍然显示。
- **自动展开进行中的 Bot** —— 有进展的分组保持展开。默认关闭，这样群聊维持你留下的折叠状态。
- **只看进行中** —— 隐藏空闲与已结束的 Assignment。

同样这三个开关也以快捷按钮形式出现在面板顶部。
