# 私有账户

打开 **Bot 私聊 → 频道设置 → 私有账户**（聊天顶部 **···** 菜单 → **频道设置…**）。这里列出这个 Bot 通过私密输入卡片向你要过的账户。这里永远不会显示密钥值，打码后的也不会。

## 查看列表

每行显示账户名、Bot 请求时说明的用途、字段名（可选字段会标出）和上次设置的时间。状态分为 **可用**、**正在替换**（有一张替换卡片还没提交）和 **不可用**（保存的账户已和原始请求对不上）。**查看原始请求** 会关闭弹窗并跳到私聊里的那张卡片。

如果无法读取列表，比如 Host 的凭据存储暂时不可用，这里会直接说明，而不是显示为空。

## 替换账户

点击 **替换**，分区和私聊里都会出现一张同账户、同字段的空白卡片。填写并提交后，Bot 下次使用时会拿到新值，不需要它做任何改动。**取消替换** 会保留旧值。如果这个 Host 未开启私密信息的执行，替换按钮不可用。

## 删除账户

点击 **删除** 并确认。本地使用会立即停止，保存的值也会立即清除。结果会显示有多少次正在进行的使用被停止、已经完成或状态不确定。删除不会在服务商那里撤销令牌；如果令牌可能泄露，请到服务商处轮换。之后 Bot 仍可以再次请求同一个账户。

命令行可以用 `deepseekbot ask-secret-accounts <bot-id>` 列出同样的账户，见 [CLI 参考](/zh/docs/bot-cli)。
