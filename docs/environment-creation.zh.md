# 在指定环境创建

打开频道新增菜单，选择创建 Bot 或频道。表单会显示目标环境。在全部视图首次创建时选择目标，之后记住上次创建到的环境；只有一个环境时可预选。在单个环境视图中，目标就是该环境。

离线目标会继续显示并保持选中。重新连接，或在全部视图中明确选择其他在线环境。创建不会排队，也不会自动改到本机。表单或请求打开后，切换浏览筛选不会改变创建目标。

新建 Bot、Git 导入和频道均通过目标环境已有的创建能力完成。远端 Bot 的可选记忆路径指向远端电脑，本机文件夹选择器不可用。ZIP 和市场导入仍使用已有本机流程：先明确切换到本机，导入表单会显示本机目标。

在单个远端环境视图中，新增菜单的分组入口打开对应环境的分组管理。可以创建分组、按 Enter 或失焦重命名、分配频道，以及上移分组或成员。变更更新该环境的 Feed。全部视图只显示平铺列表，不提供分组管理。

Agent 可通过已有在线 CLI 执行和核对同一能力。用 `--host` 和私有 `--token-file` 指向确切目标，使用 [Bot CLI](bot-cli.zh.md) 中的 `create`、`group-create`、`roster-section-*` 和 `channel-assign` 命令。UI 变更后分别读取两台 Host 的 `list`、`channels` 和 `roster`；界面结果与所属 Host 的读回是两部分证据。
