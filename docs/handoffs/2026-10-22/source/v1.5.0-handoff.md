## Remaining steps

1. Rebase the branch on main. Run `pnpm changelog:fold`, then fold the new entries into the curated 1.5.0 sections in both ledgers (same order and links in EN and ZH). Delete the fragments. Run `pnpm changelog:check` and prettier. Push with force-with-lease.
2. Vain merges #2433.
3. With Vain's explicit go: tag `v1.5.0` on the merge commit on main and push it. This starts `.github/workflows/npm-release.yml` (prepare, fresh-Profile install on DSH 0.2.0-rc.2 and 0.2.1-rc.2, then npm publish). It is the first publish of the `@botharness/cloudflared-<platform>` packages. Publishing cannot be undone.
4. Draft the GitHub Release:
   `pnpm release:draft -- --artifact deepseekbot --version 1.5.0 --tag v1.5.0 --github-release-version 1.5.0 --installable-version 1.5.0 --comparison-url https://github.com/BotHarness/DeepSeekBot/compare/v1.4.1...v1.5.0`
5. Follow-up PR: set `scripts/install-release.json` to 1.5.0, run `pnpm install:sync` and `pnpm install:check`.

The mobile apps are versioned separately and are not part of the npm release.
