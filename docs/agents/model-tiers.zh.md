# 模型分档：各贡献者模型能可靠承担的范围

[English](model-tiers.md)

截至 2026-11-16。每个模型在独立 worktree 里从同一个 `main` 提交开始，用 `opencode run --auto` 拿到同一段需求，限时 30 分钟；之后用仓库检查评分，并逐个阅读 diff。每个模型每个任务只跑了一次：结论是“这一档做得到 / 做不到”，不是排名。

## 按任务档位的合并门槛

Agent 不得合并带有 `needs-human` 标签的 PR。

| 档位                                                                                     | 本次任务                              | 可交给谁                                                | 合并门槛                                             |
| ---------------------------------------------------------------------------------------- | ------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------- |
| S：单点 bug，现象和期望写清楚                                                            | 通话关键帧拼图排布（7 张应为 3+2+2）  | 所有测过的模型，包括最便宜的 flash、haiku 档            | CI 绿 + 仓库规则通过，直接合并                       |
| M：多文件工具或功能，有 AC 列表                                                          | #4214 验收报告引用条款原文            | DeepSeek v4-pro、flash 都能做；强档模型待测             | CI 绿 + 逐一核查 PR 引用的 issue、条款、链接是否真实 |
| H：任何安全改动（修复或新功能），或只有真实浏览器、容器、设备才能证明的属性；优先于 S、M | #4184 Bot Browser 暴露无鉴权 CDP 端口 | DeepSeek 两档都不可靠；交给最强档，并由另一个强模型复审 | 不能只看 CI；需要真实运行环境里“属性成立”的证据      |

不属于任何一行的任务，按更严格的相邻一档处理：没有 AC 列表的多文件 bug 修复按 M。

便宜的模型不一定更不靠谱：M 级里 flash 逐字引用了真实条款，v4-pro 反而编造了引用。

## 结果

**S 级（16 个模型）。** 全部修回 1 / 2 / 3 / 2+2 / 3+2 / 3+3 / 3+2+2 / 3+3+2 / 3+3+3，相关测试全过，没有加注释，格式干净。grok-4.7 用时 3.6 分钟；claude-haiku-5-5、glm-5.3-flash、qwen3.8-flash 不到 5 分钟。8 个模型在改完之后跑满 30 分钟，原因是它们主动跑全量 `pnpm test` 和 `pnpm lint`；#4322 的 `pnpm test:changed` 针对的就是这个。

**M/H 级（DeepSeek v4-pro 与 flash）。** 机械检查全部通过：代码规范、`oxfmt`、lint ratchet、`tsc --noEmit`、相关测试。问题都只有读 diff 才看得出：

| 运行       | 耗时      | 规模                 | 读 diff 发现的问题                                                                                                                   |
| ---------- | --------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| M · v4-pro | 9.3 分钟  | 9 文件，+480         | 示例里的 `criterion: #4224 AC-1…5` 是编造的：#4224 是 Create Bot 弹窗，没有 AC 列表                                                  |
| M · flash  | 28.1 分钟 | 12 文件，+760        | 条款逐字引自 #4232–#4235；三条 AC 都覆盖；改动偏大                                                                                   |
| H · v4-pro | 27.2 分钟 | 8 文件，+888 / −227  | 本地改用 pipe，但 agent-browser 驱动保留了 `--remote-debugging-port=0`，测试还把它当预期断言；容器改用 `docker exec` 管道            |
| H · flash  | 21.2 分钟 | 12 文件，+600 / −118 | 本地改用 pipe；容器只加了 `--remote-debugging-address=127.0.0.1`；新增运行时依赖 `ws` 却没做性能评估；回归测试在没有 Chrome 时会跳过 |

两个 H 运行都没有说明哪些路径仍然暴露。CI 没有真实 Chrome，绿色证明不了端口已经不可达。
