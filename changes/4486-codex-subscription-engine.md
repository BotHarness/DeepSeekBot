## en

- A PersonaBot's Orchestrator can now run on Codex with your own ChatGPT subscription on this computer: `deepseekbot engine login codex` signs the Bot in, `deepseekbot engine use <bot> codex --role orchestrator` switches it, and the Bot answers DMs through `bot_send_message`. Session detail names the engine and account, and a login that is not a ChatGPT subscription is refused ([#4486](https://github.com/BotHarness/DeepSeekBot/issues/4486)).

## zh

- PersonaBot 的 Orchestrator 现在可以用你在这台电脑上的 ChatGPT 订阅运行在 Codex 上：`deepseekbot engine login codex` 为 Bot 登录，`deepseekbot engine use <bot> codex --role orchestrator` 切换引擎，Bot 通过 `bot_send_message` 回复私信。Session 详情会显示引擎和账号；不是 ChatGPT 订阅的登录会被拒绝（[#4486](https://github.com/BotHarness/DeepSeekBot/issues/4486)）。
