## en

- Notification kinds now stay on the phone and sync to every paired Host, including after pairing again; each Remote Host in the browser has its own notification choices for alerts while the page is open ([#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)).
- Browser discovery includes ordinary DM replies and replies beyond the Activity page. Offline phone copies retry while foreground; development-client AX can operate the phone's own choice, and `inbox --notifications` exposes the same Host discovery query ([#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)).

## zh

- 通知类型现在保存在手机，并同步到所有已配对 Host，重新配对后也会恢复；浏览器可为每个远程单独选择通知，仅在页面打开时提醒（[#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)）。
- 浏览器通知发现覆盖普通 DM 回复和 Activity 当前页之外的回复；手机前台自动补同步离线副本。development-client AX 可操作手机自己的选择，`inbox --notifications` 提供同一 Host 通知查询（[#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)）。
