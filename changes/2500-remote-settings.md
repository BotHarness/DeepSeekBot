## en

- Open a Remote Host's settings from its icon menu to change its default model and model presets, inspect usage and Memory activity, and preview and confirm storage cleanup on that Host ([#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)).
- Remote Host and phone default model changes preserve the observed Host revision and refuse stale or missing versions. Existing remote preset names save on Enter or blur; creating a preset remains explicit ([#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)).

## zh

- 从远程图标菜单打开设置，修改该 Host 的默认模型和模型预设、查看用量与 Memory 活动，并预览和确认清理该 Host 的存储空间（[#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)）。
- 远程 Host 与手机修改默认模型时保留读取到的 Host 版本，拒绝过期或缺失版本的写入。已有远程预设名称按 Enter 或失焦保存；新建预设仍需明确创建（[#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)）。
