## en

- The Host now removes interrupted uploads after a day and, once a day, attachments that no message, outgoing delivery or Memory file has used for 30 days, so disk use no longer grows from files nothing can show ([#2430](https://github.com/BotHarness/DeepSeekBot/issues/2430)).

## zh

- Host 现在会清除超过一天的中断上传；并每天清除 30 天内没有任何消息、待发送投递或 Memory 文件引用的附件，磁盘不再被无法显示的文件持续占用（[#2430](https://github.com/BotHarness/DeepSeekBot/issues/2430)）。
