## en

- Bots can run in any installed DSH mode, not only Tobs. Settings → Models sets the default mode for every Bot, and each Bot's settings can pick its own mode or follow the default; `deepseekbot bot-modes`, `bot-mode-default-set` and `bot-mode-set` do the same. A change applies from the Bot's next new Session.

## zh

- Bot 现在可以运行在任何已安装的 DSH 模式里，不再只能用 Tobs。在「设置 → 模型」里设定所有 Bot 的默认模式，在每个 Bot 的设置里可以单独选模式或跟随默认；`deepseekbot bot-modes`、`bot-mode-default-set` 和 `bot-mode-set` 也能完成同样的操作。改动从 Bot 的下一个新会话开始生效。
