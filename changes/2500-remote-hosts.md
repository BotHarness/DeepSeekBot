## en

- The channel list can show Remote Hosts. In the channel list's **+** menu, **Add remote** takes the pairing link from another Host's Settings → Devices → Pair a phone, so a browser can list, open and answer that Host's chats over Tailscale. Once a Remote Host is paired, an icon strip appears above the list: **All** (the default), **This host**, and one icon per Remote Host. Hover an icon for its name and unread count; an offline Host is greyed out. Each new Remote Host gets its own symbol and colour, and right-click changes the icon (symbols, emoji, colour) or removes the Host. Icons are stored in this browser only ([#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)).

## zh

- 频道列表可以显示远程 Host。在频道列表的 **+** 菜单里选 **添加远程**，粘贴另一台 Host「设置 → 设备 → 配对手机」的配对链接，浏览器就能通过 Tailscale 列出、打开并回复那台 Host 的聊天。配对远程后，列表上方出现一排图标：**全部**（默认）、**本机**，以及每个远程各一个。悬停图标可看名称和未读数；离线的远程显示为灰色。每个新远程会自动分到不同的符号和颜色，右键可更改图标（符号、Emoji、颜色）或移除。图标只保存在这个浏览器里（[#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)）。
