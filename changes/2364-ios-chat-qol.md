## en

- On iOS, pulling up past the newest message in a chat and letting go now opens the keyboard to start typing, with a hint and a light haptic once the pull is far enough ([#2364](https://github.com/BotHarness/DeepSeekBot/pull/2364)).
- On iOS, an image on the clipboard can be attached with the system Paste button above the composer, a double-tap on a message adds or takes back 👍, and a long-press on a chat in the list previews it ([#2364](https://github.com/BotHarness/DeepSeekBot/pull/2364)).

## zh

- iOS 聊天页滚到最新消息后继续上拉并松手，会直接拉起输入框和键盘开始输入；拉到位时出现提示并有一次轻触反馈（[#2364](https://github.com/BotHarness/DeepSeekBot/pull/2364)）。
- iOS 上剪贴板里有图片时，输入框上方会出现系统「粘贴」按钮，一点就加为附件；双击消息可点赞或取消 👍；在会话列表长按某个会话可以预览聊天内容（[#2364](https://github.com/BotHarness/DeepSeekBot/pull/2364)）。
