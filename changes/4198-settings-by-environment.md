## en

- Settings now separates preferences kept on this device from the current Host's options in the sidebar, shows where each page saves beside its title, and, when remote Hosts are paired, offers a top-right environment switcher that opens a remote Host's Models in the same dialog ([#4198](https://github.com/BotHarness/DeepSeekBot/issues/4198)).

## zh

- 设置侧栏把只保存在本设备的偏好与当前 Host 的选项分组列出，标题旁说明保存位置；已配对远程 Host 时，右上角可切换环境，并在同一弹窗中打开远程 Host 的「模型」（[#4198](https://github.com/BotHarness/DeepSeekBot/issues/4198)）。
