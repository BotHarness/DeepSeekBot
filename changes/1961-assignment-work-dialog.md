## en

- Assignment rows in the Sessions panel and the Group Work panel have a Work button. It opens the Assignment's work by round: what the Orchestrator asked for when it created the Assignment and each time it sent more, the MAIN steps of that round, and the Subagents it started with their model and state. The phone's Assignment detail groups its timeline by round the same way ([#1961](https://github.com/BotHarness/DeepSeekBot/issues/1961)).

## zh

- Sessions 面板和群组 Work 面板中的 Assignment 行新增“执行过程”按钮。它按轮次展示这个 Assignment 的执行：Orchestrator 创建它时和每次追加请求时的指示、这一轮的 MAIN 步骤，以及这一轮开出的 Subagent 和它们的模型、状态。手机上的 Assignment 详情也按同样的轮次分组（[#1961](https://github.com/BotHarness/DeepSeekBot/issues/1961)）。
