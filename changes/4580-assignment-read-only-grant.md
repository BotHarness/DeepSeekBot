## en

- Tob's own files folder starts writable, so its Assignments can save files with the native write tool, and a folder whose **Allow Bot to write** is off now refuses Assignment writes consistently: native file tools say the folder is read-only instead of outside the workspace, and the Assignment Shell runs read-only too ([#4580](https://github.com/BotHarness/DeepSeekBot/issues/4580)).

## zh

- Tob 自己的 files 文件夹默认可写，其 Assignment 可以用原生 write 保存文件；关闭了「允许 Bot 写入此文件夹」的目录对 Assignment 的写入保持一致：原生文件工具提示该目录只读，而不是位于授权工作区之外，Assignment 的 Shell 也以只读方式运行（[#4580](https://github.com/BotHarness/DeepSeekBot/issues/4580)）。
