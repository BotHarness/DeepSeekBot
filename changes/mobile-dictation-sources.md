## en

- Mobile dictation now uses the Host's speech-to-text Provider first and falls back to the phone's own speech recognition. When neither can dictate, the reason appears in a dialog after tapping the mic instead of a banner that stays above the composer.

## zh

- 手机端语音输入优先使用 Host 配置的语音转文字 Provider，不可用时回退到手机系统自带的语音识别；两者都无法使用时，只在点击麦克风后弹窗说明原因，不再在输入框上方常驻提示条。
