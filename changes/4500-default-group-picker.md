## en

- Settings → Models → Global default model, the onboarding model dialog and the phone's global default model picker now list Routing Groups beside models, so the default can be a group from the app. A group row shows the model it runs on now, with its provider ([#4500](https://github.com/BotHarness/DeepSeekBot/issues/4500)).

## zh

- 设置 → 模型 → 全局默认模型、引导中的模型对话框和手机端的全局默认模型选择器现在会在模型旁列出路由组，可以直接在应用里把默认模型设为路由组。路由组一行会显示它当前使用的模型及其服务商（[#4500](https://github.com/BotHarness/DeepSeekBot/issues/4500)）。
