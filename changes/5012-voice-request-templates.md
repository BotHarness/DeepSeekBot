## en

- The Host Owner can configure synchronous HTTP TTS and ASR request templates through the CLI, including JSON, multipart and SSML requests and raw, encoded or URL audio results; existing voice presets use the same engine ([#5012](https://github.com/BotHarness/DeepSeekBot/issues/5012)).

## zh

- Host Owner 可通过 CLI 配置同步 HTTP TTS 和 ASR 请求模板，支持 JSON、multipart、SSML 请求体，以及原始、编码或 URL 音频结果；既有语音预设复用同一引擎（[#5012](https://github.com/BotHarness/DeepSeekBot/issues/5012)）。
