## en

- Remote Host conversations show message images, files and request cards using the same message body as This Host; attachments and decisions go directly to the source Host with this browser's device credential ([#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)).
- Remote folder requests show localized retry guidance when browsing or authorization fails, while retaining the source Host's error for diagnostics ([#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)).
- Remote file downloads and audio playback load only after an explicit action; unavailable remote conversations retain their title and Close control, and images reopened offline offer Retry ([#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)).

## zh

- 远程会话复用本机的消息正文，显示图片、文件和请求卡片；附件读取与处理请求使用此浏览器的设备凭据，直接发往消息所属的 Host（[#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)）。
- 远程文件夹请求在浏览或授权失败时显示本地化重试提示，同时保留来源 Host 的原始错误供诊断（[#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)）。
- 远程文件下载与音频播放仅在操作后加载；远程会话不可用时仍保留标题和关闭入口，离线重开的图片显示重试操作（[#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)）。
