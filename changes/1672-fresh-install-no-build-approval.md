## en

- A fresh DSH Profile installs `deepseekbot` from the Plugins page in one step again; 1.3.0 first stopped to ask for `agent-browser` build approval. The Browser trial driver's `agent-browser` is now an optional add-on, and every release is installed into fresh Profiles on each supported DSH version before publishing ([#1672](https://github.com/BotHarness/DeepSeekBot/pull/1672)).
