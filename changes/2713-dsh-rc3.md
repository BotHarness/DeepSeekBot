## en

- Updated the development runtime and SDK to DeepSeek Harness 0.2.1-rc.3, retaining the file-tool and Go Session patches and older release checks; installation and development launch accept 0.2.0 and later prereleases independently of build pins; optional Desktop zoom checks adapter protocol and integrity instead of an exact rc ([#2713](https://github.com/BotHarness/DeepSeekBot/issues/2713)).

- Development startup protects a running Home during version switches, cleans up failed startup, and skips an already-native Go Session fix ([#2713](https://github.com/BotHarness/DeepSeekBot/issues/2713)).

## zh

- 开发运行时和 SDK 更新至 DeepSeek Harness 0.2.1-rc.3，保留文件工具、Go Session 补丁和旧版本发布检查；安装和开发启动支持 0.2.0 及后续预发布版本，不再与构建版本绑定；可选桌面缩放按适配器协议和完整性检查，不再限制具体 rc（[#2713](https://github.com/BotHarness/DeepSeekBot/issues/2713)）。

- 开发启动会阻止修改运行中的 Home，清理失败启动的进程，并跳过上游已原生修复的 Go Session 补丁（[#2713](https://github.com/BotHarness/DeepSeekBot/issues/2713)）。
