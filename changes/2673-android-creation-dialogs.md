## en

- Added native Material 3 creation Dialogs on Android for blank Bots, Git imports and Remote Host group channels. Channel creation selects multiple Bots from one computer and clears the selection when the computer changes; submitted work retains its original destination for recovery ([#2673](https://github.com/BotHarness/DeepSeekBot/issues/2673)).

## zh

- Android 使用原生 Material 3 对话框创建空白 Bot、从 Git 导入 Bot 和创建远程 Host 群频道。创建频道时可多选同一电脑的 Bot，切换电脑会清空选择；已提交的操作保留原目的地以便恢复（[#2673](https://github.com/BotHarness/DeepSeekBot/issues/2673)）。
