## en

- **Remote Host chats render like local chats.** In the web client, a chat on a Remote Host now shows images and files, tool approval cards, question cards and private input cards with the same renderer as This Host. Images and files load from that Host with this browser's pairing, and approving, answering or submitting acts on that Host ([#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)).

## zh

- **远程聊天与本机聊天显示一致**：网页端打开远程 Host 上的聊天时，图片、文件、工具审批卡、提问卡和私密输入卡都用与本机相同的渲染器显示。图片和文件通过本浏览器的配对从该 Host 加载，批准、回答或提交都在该 Host 上执行（[#2500](https://github.com/BotHarness/DeepSeekBot/issues/2500)）。
