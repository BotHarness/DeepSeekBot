## en

- On Desktop, when a Team invitation link or Switch account cannot start signing in (for example, the Host cannot be reached, or the invitation does not match the saved Host), the error now shows next to the link or username field so it can be corrected and tried again, instead of a dialog with only the error ([#5030](https://github.com/BotHarness/DeepSeekBot/issues/5030)).

## zh

- 桌面端用团队邀请链接或「切换账号」登录时，如果无法开始登录（例如连不上 Host，或邀请与已保存的 Host 不一致），错误现在显示在链接或用户名输入框旁边，可直接修改后重试，不再只显示一个错误（[#5030](https://github.com/BotHarness/DeepSeekBot/issues/5030)）。
