## en

- A message's Session links no longer stretch their connector curve across every expanded row: the curve stays beside the first row (the single link or the "N Sessions" toggle), new-Session rows below it carry no line, and the toggle's arrow points down while expanded.

## zh

- 消息上的 Session 链接展开后，连接线的弯角不再被拉长到所有行：弯角固定在第一行（单个链接或“N 个会话”折叠按钮）旁边，下面展开的新建 Session 行不再连线，展开时折叠按钮的箭头朝下。
