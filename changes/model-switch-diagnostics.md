## en

- Model pickers now show a clear hint and retry when the catalog returns no models or only one, surface failed catalog reads instead of rendering a short list, and expose an on-device catalog diagnostic with the model count, source and error ([#3](https://github.com/skyc10/DeepSeekBot/issues/3)).

## zh

- 模型选择页在目录返回 0 项或仅 1 项时给出明确提示与重试，目录请求失败时显示错误态而非静默渲染短列表，并提供含模型数量、来源与错误的真机诊断信息（[#3](https://github.com/skyc10/DeepSeekBot/issues/3)）。
