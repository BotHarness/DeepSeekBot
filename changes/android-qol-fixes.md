## en

- On Android, Enter and Ctrl+Enter on a hardware keyboard now send while WeType or a similar input method is active, instead of adding a line. The ✕ on an attachment above the message box removes it again, an upward swipe at the newest message opens the keyboard more reliably, and the recent chats on the app icon show the app icon instead of a blank placeholder (PR_LINK).

## zh

- Android 上使用微信输入法等输入法时，实体键盘的 Enter 和 Ctrl+Enter 现在会发送消息，不再只换行。输入框上方附件的 ✕ 可以正常删除附件，在最新消息处上滑拉起键盘更容易触发，长按应用图标列出的最近会话也显示应用图标，不再是空白占位图（PR_LINK）。
