## en

- Navigation items, settings sections and rows, controls, dialogs and chat bubbles now read Tobs style tokens, so every panel can switch look together. A selected item now changes only its colour, and settings rows are separated by spacing instead of lines ([#4325](https://github.com/BotHarness/DeepSeekBot/issues/4325)).

## zh

- 导航项、设置分组和设置行、控件、对话框和聊天气泡现在都读取 Tobs 风格令牌，所有面板可以一起切换外观。选中项只改变颜色，设置行之间改用留白分隔，不再画线（[#4325](https://github.com/BotHarness/DeepSeekBot/issues/4325)）。
