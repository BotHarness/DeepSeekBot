## en

- File attachments in Bot mode can be retried if the Host connection changes or the open request times out. Repeating the gesture while a request is pending shows its progress ([#4330](https://github.com/BotHarness/DeepSeekBot/issues/4330)).

## zh

- Bot 模式下，如果 Host 连接中断或文件打开请求超时，可以重试。请求仍在处理时，再次点击会提示正在打开（[#4330](https://github.com/BotHarness/DeepSeekBot/issues/4330)）。
