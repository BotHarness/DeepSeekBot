## en

- iOS Bot, Group and Bot-pair profiles now fade in and out with system Reduce Motion, including changes made while the app is running; normal page pushes and edge-back navigation are preserved ([#3104](https://github.com/BotHarness/DeepSeekBot/issues/3104)).
- Assignments now distinguish their required internal report transport from text-only work restrictions, so requests for a Markdown final answer do not leave the result in private Session text; missing reports still fail explicitly ([#3102](https://github.com/BotHarness/DeepSeekBot/issues/3102)).

## zh

- iOS Bot、群聊和双 Bot 资料页在系统「减弱动态效果」开启时使用淡入淡出，并响应应用运行期间的设置变化；普通页面推入和边缘返回保持不变（[#3104](https://github.com/BotHarness/DeepSeekBot/issues/3104)）。
- 事项明确区分内部报告提交方式与只做文字分析的工具限制，避免要求 Markdown 最终回复时把结果留在私有会话正文；未提交报告仍会明确失败（[#3102](https://github.com/BotHarness/DeepSeekBot/issues/3102)）。
