## en

- Private relay pairing now asks for a fresh code when the relay refuses phone access. Connections and the CLI distinguish a busy relay connection, an unrecognized claim, and network failures ([#5423](https://github.com/BotHarness/DeepSeekBot/issues/5423), [#5424](https://github.com/BotHarness/DeepSeekBot/issues/5424)).
