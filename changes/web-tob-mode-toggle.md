## en

- The desktop Web workspace rail has a Tob mode switch next to Home. It opens the Tob DM on its own: the Channel list and every other panel are hidden, while the Messages panel keeps its subpanels. Switching it off returns to the previous view and Channel. It works in both Simple and Advanced layouts and never changes either saved arrangement ([#3087](https://github.com/BotHarness/DeepSeekBot/issues/3087)).

## zh

- 桌面 Web 工作区导轨在「首页」旁新增 Tob 模式开关。打开后只显示 Tob 私聊：频道列表和其他面板全部隐藏，消息面板保留自己的子面板。关闭后回到之前的视图和频道。简单布局和高级布局都可使用，且不会改动任一布局已保存的排列（[#3087](https://github.com/BotHarness/DeepSeekBot/issues/3087)）。
