## en

- Added a read-only **Task board** panel to the Channel sidebar: it follows the current chat’s Assignments grouped per Bot, shows `x/y steps` progress and the step list of each Assignment, opens from the icon beside the chat header’s settings gear, stays closed by default, and remembers each chat’s open state. Closing it unmounts the panel, so it costs no requests and no timers. Refs [#2223](https://github.com/BotHarness/DeepSeekBot/issues/2223).

## zh

- Channel sidebar 新增只读的 **任务看板** 面板：按 Bot 分组跟进当前聊天的 Assignment，显示 `x/y 步` 进度与每个 Assignment 的步骤列表，入口是聊天头部齿轮旁的图标，默认关闭，并按聊天记住开合状态。关闭面板即卸载，不产生请求与计时器。Refs [#2223](https://github.com/BotHarness/DeepSeekBot/issues/2223)。
