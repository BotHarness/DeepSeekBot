## en

- Prompt presets refresh when you come back: the desktop page reads the Host again when its window regains focus, and the phone page when the app returns to the foreground, so a global preset changed on the other device shows without reopening the page. On the phone the global preset is marked with a trailing Global value instead of sharing the grey subtitle ([#4423](https://github.com/BotHarness/DeepSeekBot/pull/4423)).

## zh

- 提示词预设页在回到页面时会自动刷新：电脑端窗口重新获得焦点、手机 App 回到前台时都会重新读取 Host，在另一台设备上改的全局预设不用重开页面就能看到。手机上的全局预设改为在行尾显示「全局」，不再挤在灰色副标题里（[#4423](https://github.com/BotHarness/DeepSeekBot/pull/4423)）。
