## en

- Android chat scrolls more smoothly: loading older messages and jumping back to the newest message no longer stutter, because the conversation list and plain text messages are now drawn natively. Tapping, long-pressing and swiping to reply work as before ([#3955](https://github.com/BotHarness/DeepSeekBot/issues/3955)).
