## en

- Added native mobile blank Bot creation on a chosen paired Host, with a saved draft, same-operation recovery after an interrupted response, and completion that preserves current navigation; the CLI can query the same creation receipt. Marketplace, Git-link and Zip imports remain later slices of the accepted design ([ADR-0247](docs/adr/0247-bot-creation-and-import-recover-on-their-chosen-host.md), [#2629](https://github.com/BotHarness/DeepSeekBot/issues/2629)).
