## en

- Choose a Model Choice (a model or Routing Group) for an Orchestrator or Assignment Session in its desktop composer. A choice made during a Turn applies from the next Turn. Session timelines mark model changes and explain quota fallbacks. ([#4559](https://github.com/BotHarness/DeepSeekBot/issues/4559))

- In Team mode, members can read Session transcripts and set granted Session Model Choices for Bots they own when those Bots have no private DMs with other Humans.

## zh

- 在桌面端会话的输入框中为 Orchestrator 或 Assignment 会话选择模型选择（模型或路由组）。运行期间修改的选择从下一轮生效。会话时间线标记模型切换，并显示因额度用完而切换的原因。([#4559](https://github.com/BotHarness/DeepSeekBot/issues/4559))
- 在团队模式下，成员可以读取自己拥有的 Bot 的会话记录，并设置已获授权的模型选择。与其他用户有私聊的 Bot 不开放这两项操作。
