## en

- Bot calls use less battery and run cooler on the phone: while nobody is talking, the phone and the computer now send a small packet every 400 ms instead of fifty a second, so the phone's radio can rest between sentences ([#3481](https://github.com/BotHarness/DeepSeekBot/issues/3481)).

## zh

- 给 Bot 打电话时手机更省电、发热更少：没人说话时，手机和电脑每 400 毫秒只发一个小包，不再每秒发 50 个，手机的无线电可以在两句话之间休息（[#3481](https://github.com/BotHarness/DeepSeekBot/issues/3481)）。
