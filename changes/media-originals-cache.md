## en

- On the phone, opening an image full screen again, sharing or opening a file again, and replaying a voice message reuse the copy already downloaded instead of fetching it again. Large downloads from the computer can resume where they stopped ([#3508](https://github.com/BotHarness/DeepSeekBot/issues/3508)).

## zh

- 在手机上再次全屏查看图片、再次分享或打开文件、重播语音消息时，会直接使用已下载的副本，不再重复下载。从电脑下载的大文件中断后可以从断点继续（[#3508](https://github.com/BotHarness/DeepSeekBot/issues/3508)）。
