## en

- Skill catalogs now invalidate on Host Skill changes and changes to `SKILL.md` in a Bot's Memory Repository, with scoped live notifications and fresh `skills-list` results; Client subscriptions can refresh the open conversation without polling ([#4234](https://github.com/BotHarness/BotHarness/issues/4234)).

## zh

- Host Skill 或 Bot Memory Repository 中的 `SKILL.md` 变化后，Skill 目录会按范围失效并推送通知，`skills-list` 也会读取最新结果；Client 可通过订阅刷新当前会话，无需轮询（[#4234](https://github.com/BotHarness/BotHarness/issues/4234)）。
