## en

- Team mode gives each member their own space and lets admins create shared spaces for everyone, chosen roles or chosen people; Bots can only be given folders inside spaces their audience may use, never another member's space, Bot memory or the Host's data folder ([#4145](https://github.com/BotHarness/DeepSeekBot/issues/4145)).

## zh

- 团队模式为每位成员提供自己的空间，管理员可以为所有人、指定角色或指定成员创建共享空间；Bot 只能被授权使用其受众可用空间里的文件夹，不能使用别人的空间、Bot 记忆或这台 Host 的数据目录（[#4145](https://github.com/BotHarness/DeepSeekBot/issues/4145)）。
