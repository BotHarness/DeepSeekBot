## en

- Phone Chats now uses one list selected from All or a Host in the left drawer, with the selected view's full accessible name and icons that follow system text size. The All row shows clipped Android press feedback. Android's accent follows the current Host colour only when that Host's view is selected; All keeps the default accent and newer drawer selections win over pending switches; iOS keeps its accent and edge swipe ([#2518](https://github.com/BotHarness/DeepSeekBot/issues/2518)).

## zh

- 手机聊天页改为在左侧抽屉选择全部或一个 Host，单列表随选择筛选，标题读屏播报完整视图名称，新增图标跟随系统字号，全部行显示裁剪后的 Android 按压反馈。Android 仅在选中当前 Host 视图时使用其颜色，全部视图保留默认强调色；较早的切换完成后不会覆盖后续抽屉选择。iOS 保留原有强调色和边缘滑动（[#2518](https://github.com/BotHarness/DeepSeekBot/issues/2518)）。
