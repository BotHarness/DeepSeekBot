## en

- Tob can now run every `deepseekbot` command, not just a fixed list. Commands that only read run at once; any other command first shows you an approval card with the exact command, even with full access ([ADR-0314](https://github.com/BotHarness/DeepSeekBot/blob/main/docs/adr/0314-tob-runs-every-cli-command-with-approved-writes.md)).

## zh

- Tob 现在可以运行所有 `deepseekbot` 命令，不再限于固定清单。只读命令直接执行；其他命令会先给你一张显示完整命令的审批卡，即使开启了完全访问也一样（[ADR-0314](https://github.com/BotHarness/DeepSeekBot/blob/main/docs/adr/0314-tob-runs-every-cli-command-with-approved-writes.md)）。
