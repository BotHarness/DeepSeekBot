## en

- Added inline `/model <text>` and `/effort <text>` pickers to a Bot DM composer: they list the same catalog models and reasoning efforts as the Bot's right-click menu, filter by the typed text, mark the current choice, and apply the selection without opening the profile ([#2000](https://github.com/BotHarness/DeepSeekBot/issues/2000)).
