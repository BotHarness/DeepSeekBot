## en

- Choosing a model now works the same everywhere: the conversation header chip, the default model in settings, presets and remote Hosts open one menu with a model-family rail (DeepSeek, GPT, Claude, Gemini and more), search, each model's logo and short name, and a reasoning-effort column beside the list. On mobile, the model chooser gets family filter chips and the same logos and short names ([#4399](https://github.com/BotHarness/DeepSeekBot/pull/4399)).

## zh

- 选择模型在各处统一：对话 header 的模型 chip、设置里的默认模型、预设和远程 Host 都打开同一个选单，左侧按模型系列筛选（DeepSeek、GPT、Claude、Gemini 等），带搜索、每个模型的 logo 和简称，右侧是推理强度。移动端的模型选择页加了系列筛选 chip，并使用同样的 logo 和简称（[#4399](https://github.com/BotHarness/DeepSeekBot/pull/4399)）。
