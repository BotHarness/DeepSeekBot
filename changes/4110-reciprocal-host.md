## en

- Connect two computers with one explicitly approved reciprocal relationship, then read and message each other's Channels using separate client credentials. Disconnect revokes relationship-derived access while preserving independently paired devices ([#4110](https://github.com/BotHarness/DeepSeekBot/issues/4110)).
