## en

- Settings pages use one grouped list layout in every style: section headers, rows inside one rounded group, separators only between rows, and no cards nested inside cards. Storage, team roles, IM apps, release notes, connections and the computer page now follow it, and the Bot settings sidebar shows icons ([#4442](https://github.com/BotHarness/DeepSeekBot/issues/4442)).
- On the Connections page, existing connections and the paired-device list are grouped rows with a matching section header ([#4442](https://github.com/BotHarness/DeepSeekBot/issues/4442)).
- In Appearance, palette presets sit inside the primary color row ([#4442](https://github.com/BotHarness/DeepSeekBot/issues/4442)).

## zh

- 设置页在各风格下统一为分组列表：分区标题、同一圆角分组里的行、只在行之间有分隔线、不再卡片套卡片。存储空间、团队角色、IM 应用、更新说明、连接和电脑页都已改用这种布局，Bot 设置侧栏也加上了图标（[#4442](https://github.com/BotHarness/DeepSeekBot/issues/4442)）。
- 连接页的「已有连接」和已配对设备列表改为分组行，并使用统一的分区标题（[#4442](https://github.com/BotHarness/DeepSeekBot/issues/4442)）。
- 界面设置中，配色预设放进了「主色」这一行（[#4442](https://github.com/BotHarness/DeepSeekBot/issues/4442)）。
