## en

- Extended the existing compaction controls with Web and mobile failure recovery: compact or start a new Orchestrator Session and retry the selected safe message. Unknown model capacity uses a labeled 200K estimate; the Web composer shows current context occupancy/capacity separately from cumulative usage ([#2329](https://github.com/BotHarness/BotHarness/pull/2329), [#2335](https://github.com/BotHarness/BotHarness/pull/2335)).

## zh

- 在现有压缩能力上补充 Web 和手机端失败恢复：压缩或开启新的 Orchestrator Session 后，重试所选可安全重试的消息。未知模型容量按明确标注的 200K 估算；Web 输入框区分显示当前上下文占用／容量与累计用量（[#2329](https://github.com/BotHarness/BotHarness/pull/2329)、[#2335](https://github.com/BotHarness/BotHarness/pull/2335)）。
