## en

- The private connection, Docker relay, LAN and Tailscale screens use the same status blocks as Tobs Connect: one block per state with an icon, one main button, yellow when you need to act, and details folded away. Addresses and commands are chips you tap to copy.

## zh

- 私有连接、Docker 中继、局域网和 Tailscale 页面改用和 Tobs Connect 一样的状态块：每种状态一块，带图标和一个主按钮，需要你处理时变成黄色，细节收进折叠区。地址和命令做成点一下就复制的标签。
