## en

- Signing in to Tobs Connect on iOS no longer types every code digit twice. WorkOS's sign-in page doubled each key on iOS 27 Safari, so the app now asks for your email and the 6-digit code in its own sheet, with the code suggested from Mail, and the Connect relay checks the code with WorkOS. Google, Apple and SSO stay under Other sign-in options ([#3464](https://github.com/BotHarness/DeepSeekBot/issues/3464)).

## zh

- iOS 上登录 Tobs Connect 时，验证码不再每个数字输入两次。WorkOS 登录页在 iOS 27 Safari 上会把每次按键输入两遍，现在 App 用自己的页面填写邮箱和 6 位验证码（可以直接用邮件里的验证码建议），由 Connect 中转去 WorkOS 验证。Google、Apple 和 SSO 登录放在“其他登录方式”里（[#3464](https://github.com/BotHarness/DeepSeekBot/issues/3464)）。
