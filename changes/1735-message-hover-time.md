## en

- Grouped messages now show each message's own time in the left avatar column on hover, with the group avatar yielding that slot so the timeline does not move. When a message has reaction chips, the time stays level with the bubble bottom instead of dropping below them ([#1735](https://github.com/BotHarness/DeepSeekBot/issues/1735)).

## zh

- 合并组内的消息悬停时，现在改为在左侧头像列显示该消息自身的时间；组头像让出该位置，时间线不会移动。消息下方有表情回应时，时间仍与气泡底边对齐，不会落到表情下方（[#1735](https://github.com/BotHarness/DeepSeekBot/issues/1735)）。
